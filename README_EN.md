## 🇺🇸 Overview

**Letiao ATS** is a cutting-edge Enterprise Recruitment SaaS framework structurally master-crafted to embed **Aesthetics-driven frontend manifestations** (primarily channeling Dark Cosmic Glassmorphism principles) sitting comfortably on a **Heavy-Duty .NET 8 C# Core**. Crucially, we deliver automation mapped closely to **Large Language Models (LLMs)** bringing true generative convenience deep into HR mechanics simultaneously solving cost/time issues and elevating platform engagements.

### ✨ Key Highlights
* 🎨 **Immersive Glassmorphism UX**: Completely programmed layout matrices enforcing translucent acrylics, vibrant gradients, and ultra-smooth CSS neon-hover interactions rendering standard back-office softwares completely obsolete in comparisons.
* 🤖 **LLM-Powered Resume Intelligence**: Deep-wired into Volcengine's `Doubao-Seed` AI layer via secure proxy gateways—giving your HRs an instant split-screen architecture showing the native PDF viewer immediately alongside 100% LLM-automated metadata entity extractions.
* 🛡️ **Sleek Anti-Collision Constraints**: Lightning-fast strict C#-layer protocols erasing cross-system double registry pipelines forever, effortlessly transferring underlying Database friction into elegant global Business Exception alerts mapped smoothly over RESTful payloads.
* 🚀 **Hyper-Performance Stack**: Deploying full C# 12 primary structural designs wired into lightweight mappings via Dapper Micro-ORM, stripping extensive bloatwares for maximum raw database querying bounds.

## 🛠 Tech Stack

### 🖥️ Frontend
- **Core Framework**: `Vue 3` (Composition API) + `Vite` serving flawless Hot Modular Replacements.
- **UI Visual Design**: `Element Plus` (Radically revamped with custom CSS tokens to adhere exclusively towards our internal Glass aesthetic).
- **Network**: `Axios` wired up flawlessly over localized dynamic proxy intersections carrying native JWT-State sessions natively via global interceptors mapping.

### ⚙️ Backend (Letiao.ATS.Api)
- **Web API Layer**: `.NET 8`, taking extensive advantage of modern minimalist Controllers and dependency injection mechanics.
- **Data Engine Mapping**: `Dapper` mapping POCOs at scale locally without the legacy EF Core drag constraints.
- **Authentication**: Microsoft standard `JwtBearer` extensions.
- **Text Processor**: Employing `UglyToad.PdfPig` executing raw PDF byte-level stripping algorithms fueling our AI data pipelines seamlessly.

### 🗄️ Database
- **Engine**: Native `MySQL 8.x` mapped over localized tables executing stringent Relational Foreign keys over User/Roles/Pipeline mechanics preserving pristine state consistency.

## 🏗️ Architecture Glimpse

- **Domain-centric Isolation**: Strict entity segregation from presentation logic.
- **Global Error Failsafes**: Leveraging ASP.NET Middlewares to centralize HTTP 409 collisions seamlessly sending standard `ApiResponse` objects locally to Axios interceptors without crashing endpoints.
- **DotNetEnv Local Secrecy**: Gitignored AI Model keys (`.env`) safeguarding endpoints whilst operating purely over scalable Volcengine AI interfaces locally.
- **Smart Data Structures**: Dynamic recursive hierarchy builder constructing Nested Trees in linear $O(n)$ complexity out of flat relational databases tables serving the Organization Structure frontend visualization block.

## 🧑‍💻 Getting Started

> Ensure you have **Node.js 18+** and **.NET 8.0 SDK** installed globally.

### 1. Database Configuration
1. Run `database/init.sql` directly into your MySQL environment.
2. The initial default username acts over `admin` with password `Admin@123` respectively.

### 2. Backend Bootstrapping
```bash
> cd backend
> dotnet restore
> dotnet run   # Operates on localhost:5244
```
*(Make sure to create `.env` manually in `/backend` referencing your `VOLCENGINE_API_KEY` for AI features!)*

### 3. Frontend Initialization
```bash
> cd frontend
> npm install
> npm run dev  # Vite starts on localhost:5173
```
